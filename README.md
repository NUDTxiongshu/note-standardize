# note-standardize

把学习材料做成**树形层级编号大纲**（思维导图式笔记）的 agent skill。
通用，不限学科。已在英语文法材料上做过完整评估。

## 它做什么

给一份学习材料，产出两样东西：一棵树，和一份可导入思维导图软件的格式。

```
单句：五种基本句型
├── 1. 主部与谓语
├── 2. 句型分类的依据
├── 3. 五种基本句型
│   ├── 3.2 S + V
│   │   ├── 例：The dog barked at the mailman.
│   │   │   ├── 谓语核心 bark 不及物，不需宾语
│   │   │   └── at the mailman 是介词短语当副词
│   └── …
├── 4. 补语的词类
└── 5. 分辨句型
```

## 核心方法

**两段，两个执行者。**

1. **摊开**：照作者结构原样写成树，一个概念一个节点，不做优化
2. **减法**：换一个没写过 draft 的执行者，循环做四类操作——归位（节点属于哪个父节点）、归纳（插中间概念）、合并（去重）、并合（拼回碎片）

**为什么必须换人**：写 draft 的人会认同自己的结构，看不出哪里该下沉。实测同一份材料，同一个 agent 做阶段二只归位 2 次得 7 层，换人做归位 20 次得 10–11 层。

## 安装

```bash
npx skills add NUDTxiongshu/note-standardize
```

或手动把 `SKILL.md` 放到你的 skills 目录。

## 用法

```
agent A：读材料 → 摊开 → draft.md
         （摊完就停）
   ↓ 换人，或开新会话
agent B：只读 draft.md → 循环减法 → 最终树
```

## 验证过的效果

在英语文法材料上按 8 条断言做过对照实验（详见仓库内 `evals/`）：

| 配置 | 通过率 |
|---|---|
| 不用 skill | **57.1%**（12/21） |
| 用 skill（283 行初版） | 95.2%（20/21） |
| 用 skill（168 行定版） | **100%**（24/24，三章） |

8 条断言覆盖：格式、单根、编号、节点数、每节点字数、一级分支数、深度、导航节点过滤。

**已知局限**：断言只能测结构，测不出「例句的解释挂对了没有」这类语义问题，仍需人工读一遍产出。
