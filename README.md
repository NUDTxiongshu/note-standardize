# note-standardize

[![skills.sh](https://skills.sh/b/NUDTxiongshu/note-standardize)](https://skills.sh/NUDTxiongshu/note-standardize)

把用户指定的学习材料整理成概况骨架与细讲节点并存的树形编号笔记。适用于教材、课件、课程材料和需要保留公式推导的学习任务。

## 输出结构

内部节点概括类别、关系和结论；末端节点按主材料详细解释定义、公式、条件、推导、结果含义和有教学作用的例子。复杂推导留在同一分支，按顺序分成有编号的步骤。

## 工作流程

1. 按用户指定的主材料通读，列出概况骨架、理由、生长记录；数学/科学材料同时建立逐页公式台账。
2. 独立审查者先对照主材料审骨架，结构问题结案后再填写细讲内容。
3. 第二遍逐支填入细讲；公式与解释相邻，复杂推导按步骤展开。
4. 同一审查者对照主材料检查遗漏、错挂、分散内容和公式覆盖，并逐项结案。

## 公式材料

先查 PDF/文档文字层；文字层为空时放大识图。台账记录来源页、公式原文或图像位置、条件/讲解、笔记节点号和核验状态。OCR 不确定的符号标为待核；未核实项不记为已覆盖。

## 安装

```bash
npx skills add NUDTxiongshu/note-standardize
```

## 回归用例

evals/ 包含英语文法三章结构用例，以及 AR(1)/MA(1) 细讲用例，检查公式、假设、推导步骤与结果解释是否相邻完整。验收不以固定节点数、平均字数或压缩率代替内容质量。

## 文件

```
SKILL.md                  skill 本体
GLOSSARY.md               概况/细讲与公式覆盖术语
evals/                    结构和细讲回归用例
scripts/check_outline.py  树形格式和编号检查
```

检查脚本只验证树形与编号；内容完整度、公式正确性和节点归属须对照主材料审查。
